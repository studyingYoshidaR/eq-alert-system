# eq_src_backup — ソースアーカイブ

`eq_src/` の過去スナップショット。特定時点のソース全体をフォルダ単位で保存した**参照用アーカイブ**であり、実行対象ではない。

## 内容

| フォルダ | 時点 |
| --- | --- |
| `eq_src_until260110/` | 2026-01-10 時点の `eq_src` |
| `eq_src_until_260116/` | 2026-01-16 時点の `eq_src` |
| `eq_src_until_260402/` | 2026-04-02 時点の `eq_src` |

各フォルダ名の `until<YYMMDD>` は「その日付時点までの状態」を表す。

## 用途・注意

- 過去実装の参照・比較用。**現行の開発は [eq_src/](../eq_src/) で行うこと**。
- ここのコードは古く、現行モジュール構成（`eq_ring_monitor.py` / `eq_site_calibration.py` 等の精度向上モジュール）を含まない可能性がある。
- 履歴管理は本来 Git が担うため、新規のバックアップフォルダ追加は原則不要。
