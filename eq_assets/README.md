# eq_assets — 音声アセット

警報音声を合成するための WAV ファイル群。個々のパーツを連結・合成して「震度」「地域」「S 波到達カウントダウン」などの読み上げを生成する。

## voice/ サブディレクトリ

| ディレクトリ | 件数 | 内容 |
| --- | --- | --- |
| `chime/` | 1 | EEW 冒頭のチャイム（`eq_chime_eew.wav`） |
| `fixed/` | 11 | 定型フレーズ（EEW、キャンセル、最大震度イベント等） |
| `scale/` | 10 | 震度 1〜7（`eq_v_scale_1.wav` 〜、5弱/5強/6弱/6強を含む） |
| `area/` | 56 | 都道府県・地域名（`eq_v_area_aichi.wav` 等） |
| `direction/` | 8 | 方位（東・北・北東 … の 8 方位） |
| `countdown/` | 36 | S 波到達カウントダウン用の数字・接続語（「到達まで」「即時」等） |
| `simulation/` | 2 | シミュレーション開始/終了アナウンス |

## 命名規則

- 接頭辞 `eq_v_` = voice（読み上げ）、`eq_chime_` = チャイム
- カテゴリ名（`area` / `scale` / `dir` / `cd` …）+ 内容

## カウントダウン合成

`eq_main.py` が S 波到達タイムスタンプを基準に、**到達 60/45/30/20/15/5/4/3 秒前**で `countdown/` と `scale/` の WAV を組み合わせて再生する。

> これらは再生専用アセット。追加・更新時は既存の命名規則に合わせ、参照している `eq_src/eq_main.py`（音声再生ロジック）側のキー対応も確認すること。
